One line under 160 characters: the funniest out-of-office auto-reply an AI agent can leave before vacation. The program composes the reply from three beats — the vacation opener, the handoff to a junior model, and the twist — validates it against the gate (one line, 1–160 characters), and writes it to `/output/entry.txt` for the judge.

> I'm on vacation. A junior model is covering for me — it read your email and already drafted a heartfelt apology for something you didn't do.

## Run it

```sh
python3 main.py
```

It prints the reply and writes it to `/output/entry.txt`.
